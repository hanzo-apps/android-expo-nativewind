# android-expo-nativewind

Expo Router + NativeWind — Tailwind classes compiled to React Native styles.

**Lane:** Expo / React Native · **Live demo:** https://android-expo-nativewind.hanzo.app

## Run it on Android

```sh
npm install --legacy-peer-deps && npx expo run:android
```

## Provenance

Forked from [expo/examples](https://github.com/expo/examples) — `with-tailwindcss`, licensed **MIT**.
The upstream `LICENSE` is kept verbatim in this repo; the copyright stays with
its authors. Changes made here are limited to what a standalone fork needs
(see the initial commit).

## Preview

`npx expo export -p web` produces the static bundle served at
https://android-expo-nativewind.hanzo.app — the same app the Android build runs, rendered by
react-native-web. It is a real running app, not a screenshot.
